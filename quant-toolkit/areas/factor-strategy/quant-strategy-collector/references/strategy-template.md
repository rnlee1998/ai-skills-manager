# 量化策略文档模板

以下为标准化量化策略文档的结构模板。生成新策略文档时，严格按此结构组织内容。

---

## 模板结构

```markdown
# {策略名称}

## 策略背景

- **策略类型**：{趋势跟踪/均值回归/套利/轮动/多因子/其他}
- **适配标的**：{个股/ETF/指数/期货合约等}
- **适用市场**：{A股/港股/美股/期货市场等}
- **策略来源**：{原始研报/论文标题}，{作者/机构}，{发布日期}
- **核心标签**：{用3-5个关键词概括策略特征}

## 核心逻辑

{用2-3段文字阐述策略的底层逻辑和理论基础。包括：策略基于什么市场现象、核心假设是什么、为什么有效。}

## 交易规则

### 选股/选标的逻辑

{详细描述标的筛选条件，包括因子选择、筛选标准、权重分配等。}

### 入场条件

{列出触发买入信号的具体规则。条件须量化、可执行。}

### 出场条件

{列出止盈止损规则和信号退出条件。包括止损线、止盈目标、信号反转退出等。}

### 仓位管理

{描述资金分配和仓位调整规则。如原始资料未提及，标注"原始资料未提及"。}

### 调仓频率

{描述策略的调仓周期和频率。}

## 回测表现

| 指标 | 数值 |
|------|------|
| 回测区间 | {起止日期} |
| 基准指数 | {比较基准} |
| 年化收益率 | {百分比} |
| 最大回撤 | {百分比} |
| 夏普比率 | {数值} |
| 胜率 | {百分比} |

> 若原始资料未提供回测数据，标注"原始资料未提供回测数据"。

## 适用场景

{描述策略适合的市场环境、资金规模、投资者类型等。}

## 策略优势

1. {优势一}
2. {优势二}
3. {优势三}

## 风险提示

1. {风险一}
2. {风险二}
3. {风险三}

## 关联策略

{若与策略库中已有策略存在关联（同框架不同参数/标的等），在此说明。若无关联，标注"无"。}

---

> **免责声明**：本策略文档仅供学习研究参考，不构成任何投资建议。量化策略存在回测与实盘差异风险，实际应用前须独立验证。
```

## 模板使用说明

1. 每个花括号 `{...}` 为占位符，替换为从原始研报/论文中提取的实际内容
2. 所有模块必须保留，若原始资料对应模块无数据，标注"原始资料未提及"
3. 交易规则部分须尽量量化，避免模糊表述
4. 回测表现优先使用原始资料中的数据，不编造
5. 策略优势和风险提示各至少列出3条
6. 免责声明为固定内容，所有文档必须包含
