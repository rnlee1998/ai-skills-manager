# 智能去重规则

本文件定义策略去重的核心比对维度和重复判定标准，供阶段三"智能去重"执行参考。

## 去重核心维度

对新采集策略与已有策略库中的每篇文档，从以下六个维度逐项比对：

### 维度一：核心交易逻辑

- 比对策略的理论基础和底层逻辑
- 判断是否基于相同的市场现象和假设
- 示例：两篇策略都基于"动量效应在ETF标的上持续有效" -> 高度相似

### 维度二：交易框架

- 比对策略的整体交易结构（入场 -> 持仓 -> 出场 -> 调仓）
- 判断是否使用相同的交易流程和信号机制
- 示例：两篇策略都使用"动量排名 + 定期调仓 + 波动率过滤" -> 高度相似

### 维度三：选股/选标的逻辑

- 比对标的筛选条件和因子选择
- 判断是否使用相同的因子组合和筛选标准
- 示例：两篇策略都选择"过去20日涨幅最高的5只行业ETF" -> 高度相似

### 维度四：入场/出场条件

- 比对入场信号和出场规则的具体参数
- 判断入场/出场条件是否本质一致
- 示例：两篇策略入场都用"动量排名前3"，出场都用"跌破均线" -> 高度相似

### 维度五：适配标的

- 比对策略适用的标的类型
- 判断是否针对相同或高度重叠的标的池
- 示例：两篇策略都在"沪深300成分股"上操作 -> 标的重叠度高

### 维度六：适用市场

- 比对策略适用的市场环境
- 判断是否针对相同市场
- 示例：两篇策略都在A股市场操作 -> 市场一致

## 重复判定标准

### 高度重复 -> 跳过

满足以下任一条件，判定为高度重复，跳过不生成新文档：

1. **维度一 + 维度二均一致**：核心逻辑和交易框架都一致
2. **六个维度中四个以上一致**（含维度一或维度二）
3. 策略名称、作者、来源完全一致
4. 来自同一原始研报的不同转载

### 部分相似 -> 生成并标注关联

满足以下条件，判定为部分相似，生成新文档但在"关联策略"模块标注：

1. 交易框架一致但参数不同（如调仓频率、持仓数量不同）
2. 核心逻辑一致但适配标的不同（如一个针对行业ETF，一个针对宽基ETF）
3. 入场/出场条件相似但阈值参数不同
4. 同一策略思路的不同改进版本

### 完全不同 -> 正常生成

六个维度中不一致项超过四个，判定为完全不同，正常生成新文档。

## 去重执行流程

1. 读取策略库目录下所有已有 `.md` 文档
2. 提取每篇文档的以下关键信息：
   - 核心标签（策略背景部分的"核心标签"字段）
   - 核心逻辑模块全文
   - 交易规则各子模块全文
   - 适用市场和适配标的
3. 将新策略与每篇已有策略按六维度逐项比对
4. 记录比对结果，统计一致维度数
5. 根据判定标准决定：跳过 / 生成并标注 / 正常生成
6. 可选：执行 `scripts/dedup_check.py` 辅助关键词比对

## 辅助脚本使用方式

```bash
python scripts/dedup_check.py --library <策略库路径> --input <新策略摘要文件>
```

- `--library`：策略库目录路径，包含已有的 `.md` 文档
- `--input`：新策略核心摘要文本文件路径（包含策略名称、类型、核心逻辑等关键信息）

脚本输出每篇已有文档与新策略的匹配分数和匹配关键词，辅助判断重复程度：
- 分数 > 0.6：高度重复风险，建议跳过
- 分数 0.4-0.6：中等相似，建议生成并标注关联
- 分数 < 0.4：低相似，可正常生成

## 注意事项

1. 去重判定从严不从宽，宁可跳过也不生成冗余文档
2. 对于同一策略的不同版本或迭代，保留最新版并在文档中注明历史版本
3. 若两篇文档来自同一研报的不同转载，判定为高度重复
4. 对于来自不同机构但策略核心完全一致的策略，判定为高度重复
5. 若新策略是已有策略的改进或变体，判定为部分相似，需在关联策略中注明
