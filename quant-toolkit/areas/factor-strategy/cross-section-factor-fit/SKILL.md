# 截面排序因子对执行型策略的适配性检验

## 何时用

- 用户有一个**执行型**策略（逐标的、绝对阈值、二值买/卖信号，无横截面比较），想叠加截面排序来"选股"；
- 用户问"该配哪些因子""多因子打分怎么接进去"；
- 用户加了排序但没效果，想知道为什么。

## 第一条铁律：区分全截面 IC 与**候选集条件 IC**

**执行型策略的入场信号本身就是一个筛选器。** 如果入场要求"创新高 / 动量转正 / 突破均线"，那么走到决策集里的标的，动量维度**已经在高分位**。此时在全池截面上算的 IC 会给出**方向上完全相反的乐观结论**。

- 必须**只在候选集内部**（当日真正会下单的那批标的）算 rank IC。
- 实测样例：某策略全池 mom250 IC=+0.033(t=3.10)、dd250 +0.040(t=4.90)、sharpe250 +0.042(t=4.14)；同一批因子在候选集内变成 -0.002 / +0.025 / -0.002，**t 值全部 <1.1**。
- 若不做这一步，会得出"加排序能提升选股"的错误结论。

## 五步流程

### 1. 复刻执行信号，确定"候选集"
不要用"有信号"替代"会下单"。把买入条件全部复刻：待买条件、买点门、动量过滤、分类过滤。
输出每日候选集大小分布 —— 这是判断排序是否有意义的前提。

**决策集宽度判据**：若「候选数中位数 ≤2」或「候选≤2 的交易日占比 >50%」，则**排序在统计上不成立**，不要往下做因子研究，直接转向资金分配问题。
（实测样例：可买只数均值 2.8、中位 2，61.4% 的交易日 ≤2 只。）

### 2. 算候选集的有效独立赌注数
```python
w = corr_matrix_eigenvalues
N_eff = (w.sum() ** 2) / (w ** 2).sum()     # participation ratio
```
- `N_eff / 名义只数 < 20%` → 严重冗余，**相关性去重是最高优先级因子**。
- 同时算**同日候选之间的平均相关 r**：若高于全池平均，说明**信号会聚集在同一题材**，信号本身没有分散化能力。

### 3. 双口径 rank IC
对每个因子、每个前向期 h∈{3,5,10,20,40}：
```
全池口径：mask = 池内有效 & 因子有限 & 前向收益有限，要求 n>=8
候选集口径：mask = 候选集 & ...，要求 n>=3
rank IC = 逐日 Spearman(因子, 前向收益)，再对日序列做 t = mean/(std/sqrt(n))
```
**判据**：候选集内 |IC| < 0.03 或 |t| < 2 → 该因子不可用。

### 4. 决策相关检验（最关键，别省）
只在候选 ≥3 只的日子，比较 **top1 / 等权候选 / bottom1** 的前向收益：
```
d = top1 - 候选集等权        # 这是"排序有没有加值"的直接答案
t = d.mean() / (d.std(ddof=1)/sqrt(len(d)))
```
- **成本门槛**：往返成本 ≈ 2×(滑点+佣金)。若 `d.mean()` 低于往返成本，且排序会带来额外换仓 → 不可用。
- 若排序只用于"钱不够时决定先买谁"（不额外换仓），边际成本为零，但要求 t 显著。

### 5. 结构化因子建议（按"是否需要预测收益"分组）
**不要**按动量/波动/资金流这类传统分类给建议——那会掩盖"根本不依赖预测"的那一类因子，而那一类恰恰是唯一可靠的。

| 类别 | 依赖预测 | 用途 |
|---|---|---|
| A 结构性 | 否 | 相关性去重 / 容量与滑点校准 / 止损波动率缩放 |
| B 趋势类 | 是 | 仅池层面方向判断 |
| C 反转与高频 | 是 | 通常不适配，需实测反证 |

## 高价值的结构性因子（不依赖收益预测，弱样本下照样有效）

1. **相关性去重**：候选集内 complete-linkage 聚类，r≥0.90 每簇只留一个代表。
   **不要用 single linkage**（链式误合并）。
2. **容量校准**：核对"单只预算 / ADV"。回测里若滑点是固定值、与流动性无关，则**系统性高估低流动性标的收益**，应按 ADV 分层设滑点。
3. **止损波动率缩放**：固定百分比止损的**绝对水平**对高波动标的是噪声、对低波动标的是趋势。
   诊断口径：`8% / 日波动` = 相当于几天的 1σ；以及**入场日**（不是全样本）的止损触发率。
   实测：低波动 1/3 组触发率 62.1% vs 高波动组 91.0%；同一 8% 相当于 7.5 天 vs 4.2 天 1σ。
   → 建议 `止损_i = 阈值 × σ_i / σ_median`。

## 常被提出但实测无效的因子（先验低，别浪费时间）

| 因子 | 为什么无效 |
|---|---|
| 短期反转 / 低偏离 | 与"创新高"型入场信号方向冲突；实测候选集内 top1−等权为**负**且显著（t≈-2.8） |
| 趋势质量（ER、R²、站上均线比例） | 动机好（移动止损会优先洗掉锯齿趋势），但实测候选集 IC≈0。留在**门槛位**，不要拿去排序 |
| 横截面离散度择时 | 理论上离散度=alpha 空间，实测全池离散度 vs 候选集前向离散度**r≈-0.01**，无效 |
| 分池标签当排序轴 | 单区间结论不可外推（实测单区间 t=-4.35，长样本反向 t=+2.30） |
| 高频/ML 因子挖掘 | 截面只数少 → IC 标准误 ≈ 1/√N，需 \|IC\|>0.3 才显著；极易过拟合 |

## 输出格式

1. 先给一句话结论：**排序能不能解决用户想解决的问题**；
2. 决策集宽度表（均值/中位/分位/占比）+ 有效独立赌注数；
3. 双口径 IC 对比表（全池 vs 候选集）；
4. top1 vs 等权的决策检验表 + 成本门槛；
5. 按 A/B/C 三类的因子适配性评级；
6. 接入点按性价比排序（**预算归一化通常 > 去重 > 止损缩放 > 排序**）；
7. 验证协议：只在候选集内算 IC、必打同池等权与候选集等权双基准、多点重复、消融。

**重要提醒**：执行型策略的常见病是**结构性欠配**（预算分母用"池只数"而不是"信号数"，导致长期低仓位）。这个问题的收益远大于任何因子优化，**应先修它**。

## 坑

- **前向收益的 NaN 统计**：`nanstd/nanmax` 遇到全 NaN 切片会静默返回 nan 并只给 RuntimeWarning。定位后要显式过滤 `np.isfinite` 再统计。
- **pandas 3.x 的 `to_numpy(dtype=float)` 返回只读数组**，`arr[mask] = x` 会报 `ValueError: assignment destination is read-only`，必须 `.copy()`。
- **PowerShell 工具把 stderr 的 RuntimeWarning 当成 NativeCommandError**，脚本实际成功也会返回 exit code 1。判断成败要看**输出文件是否生成**，不要只看 exit code。
- 长历史数据源：baostock 可能只返回近期窗口；新浪 `getKLineData` 的 `datalen=1500` 可拿约 6 年，但**不复权、无 amount 字段**（用 volume×close 近似）。不复权对高分红标的会引入 1~3% 假下跌，需在局限里写明。
- 份额折算会造成假日跳空（|对数日收益|>0.25），必须先置 0 再算收益/相关性。
