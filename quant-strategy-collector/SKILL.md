# 量化策略采集器 (Quant Strategy Collector)

## 概述

本技能为全自动量化策略采集与整理工具，可全网定向抓取各类正规金融机构公开研报、行业论文中的量化交易策略，自动拆解、提炼核心逻辑，规整为标准化策略文档，搭建专属量化策略知识库。全程自动化执行、智能去重，无需人工干预。

## 触发条件

### 通用触发

当用户提及以下关键词或表达以下意图时，自动触发本技能：

- "采集量化策略"、"搜集量化策略"、"整理量化策略"
- "量化策略库"、"策略知识库"
- "抓取策略研报"、"策略报告采集"
- "找策略"、"搜索量化策略"
- 用户明确要求从研报、论文中提取量化交易策略

### 专项触发（ETF轮动）

当用户输入关键词包含"ETF轮动策略"时，立即触发全网定向检索模式：

- 优先搜集主流ETF轮动模型
- 覆盖行业轮动、宽基轮动等相关策略
- 按统一规则提炼、整理、去重并生成专属策略文档

## 核心工作流程

执行策略采集时，严格按照以下四个阶段顺序执行：

### 阶段一：定向检索

1. 根据触发关键词确定检索主题（通用量化策略 或 ETF轮动策略专项）
2. 参照 `references/data-sources.md` 中的数据源清单和检索关键词策略
3. 使用 WebSearch 工具执行多轮检索，覆盖以下维度：
   - 券商研究所公开量化策略研报
   - 公募/私募基金公司策略分析报告
   - 量化研究机构专题论文
   - 金融财经平台策略复盘文档
4. 对每条检索结果，使用 WebFetch 获取完整内容
5. 精准筛选：保留包含明确量化交易策略的文档，剔除水文、重复资讯、非策略类内容

**筛选标准：**
- **保留**：含有明确选股/选标的逻辑、入场/出场规则、回测数据等策略核心要素的文档
- **剔除**：纯市场评论、无策略细节的新闻快讯、重复转载内容、无法获取全文的页面

### 阶段二：策略拆解与提炼

对每篇筛选通过的文档，提取以下核心信息：

| 维度 | 提取要点 |
|------|----------|
| 策略名称 | 策略全称及简称 |
| 策略类型 | 趋势跟踪/均值回归/套利/轮动/多因子等 |
| 核心交易思路 | 策略的底层逻辑和理论基础 |
| 选股/选标的逻辑 | 标的筛选条件、因子选择 |
| 入场条件 | 触发买入的具体规则 |
| 出场条件 | 止盈止损规则、信号退出条件 |
| 适用市场 | A股/港股/美股/期货等 |
| 适配标的 | 个股/ETF/指数/期货合约等 |
| 策略优势 | 该策略的核心竞争力 |
| 风险提示 | 策略的局限性和潜在风险 |
| 回测逻辑 | 回测区间、基准、绩效指标 |
| 数据来源 | 原始研报/论文的出处和作者 |

### 阶段三：智能去重

在生成新文档前，执行去重检查：

1. 读取策略库目录下所有已有 `.md` 文档
2. 参照 `references/dedup-rules.md` 中的去重比对维度，将新策略与每篇已有策略逐项比对
3. 可选执行 `scripts/dedup_check.py` 辅助比对（传入新策略核心摘要和策略库路径）
4. 判定标准：
   - **高度重复（核心逻辑+交易框架一致）**：跳过，不生成新文档，记录日志
   - **部分相似（框架一致但参数/标的/市场不同）**：生成新文档，在文档中标注与已有策略的关联
   - **完全不同**：正常生成新文档

### 阶段四：文档生成

1. 参照 `references/strategy-template.md` 中的标准化模板结构生成 Markdown 文档
2. 文档命名规则：`{策略类型}_{核心特点}.md`（如 `ETF轮动_动量趋势跟踪.md`）
3. 输出到策略库目录（默认为用户工作区下的 `quant-strategy-library/` 目录，用户可指定）
4. 每篇文档保持独立、完整、可检索

## 输出文档规范

1. **单策略单MD文档**：一篇策略一个 `.md` 文件，不合并多篇策略
2. **文档命名清晰**：包含策略类型 + 核心特点，便于检索
3. **结构化呈现**：分模块梳理，参考 `references/strategy-template.md`
4. **保留核心精髓**：剔除冗余废话和无关铺垫，保证内容专业、实用、可落地
5. **标注来源**：文档末尾注明原始研报/论文的出处

## 资源说明

### references/

- **strategy-template.md** — 标准化策略文档模板，定义策略背景、核心逻辑、交易规则、适用场景、风险提示等模块结构
- **data-sources.md** — 数据源指南，整理全部主流权威量化策略数据源及检索关键词策略
- **dedup-rules.md** — 去重规则，定义核心比对维度和重复判定标准

### scripts/

- **dedup_check.py** — 去重检查脚本，对新采集策略与已有策略库执行关键词比对，输出疑似重复列表

## 执行约束

1. 仅采集公开可访问的正规金融机构资料，不采集需付费或违反版权的内容
2. 策略内容忠实于原始来源，不编造策略细节或回测数据
3. 若原始文档信息不完整（如缺失出场规则），在文档对应模块标注"原始资料未提及"
4. 去重判定从严不从宽，宁可跳过也不生成冗余文档
